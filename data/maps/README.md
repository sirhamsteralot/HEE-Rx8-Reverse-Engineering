# Extracted calibration maps

Per-ROM dumps of every lookup table found by scanning the Denso descriptor
region. Generated by `utilities/scripts/extract_maps.py`; cross-ROM diff by
`utilities/scripts/diff_maps.py`.

## Layout

```
data/maps/<rom-id>/
  manifest.json          ROM id, SHA-256, table counts by dimension/type, scan stats
  index.tsv              one row per table: descriptor addr, dimension, count, type,
                         axis/data addresses, monotonic flag
  tables/tbl_<desc>.json full fidelity: axis values + data values + metadata
  tables/tbl_<desc>.csv  human-readable (2D: axis,value pairs; 3D: y\x matrix)
  scalars.json           verified literal-pool float32 scalars (not tables): exact
                         bit pattern, value, every ROM address, reference-ROM
                         addresses, evidence trail (generated by extract_scalars.py)
  scalars.tsv            same as one row per scalar
```

`cross_rom_diff.json` at the top level: tables matched across ROMs by
(dimension, counts, type, axis values) with per-cell differences vs the
reference ROM (60E15120_N3J1E). `cross_rom_scalars.json` (from
`utilities/scripts/extract_scalars.py --all`): per-ROM addresses of each
verified scalar's exact bit pattern; same bits => same value wherever present.

## Descriptor format (verified against ROM bytes + lookup code)

Big-endian. 2D base = 12 B `>HBBII` (n, type, reserved, axis_ptr, data_ptr);
2D scaled = 20 B (base + multiplier:f32 + offset:f32). 3D base = 20 B
`>HHIIIB` + 3 pad (nx, ny, ax_ptr, ay_ptr, data_ptr, type); 3D scaled = 28 B.

Type codes (dispatch tables 0x2098/0x210c → symbols.tsv):
0=float32(4B), 4=uint8(1B), 8=uint16(2B), 12=int8(1B), 16=int16(2B).
Axes are always float32.

## ROMs extracted

10 stock ROMs (via pinned submodule) + 1 own factory dump (60E0G500/N3ZHEC).
Table counts: 381–587 per ROM, 0 non-monotonic axes everywhere.

Regenerate:
```sh
for rom in submodules/Mazda_RX8_PCM_ReverseEngineering/Stock_ROMs/*.bin; do
  python utilities/scripts/extract_maps.py "$rom"
done
python utilities/scripts/extract_maps.py binaries/dumps/60E0G500_N3ZHEC.bin
python utilities/scripts/diff_maps.py
python utilities/scripts/extract_scalars.py --all   # scalars.* per ROM + cross_rom_scalars.json
```

## Validation

- All 478 RX8Defs-matched descriptors for 60E15120_N3J1E found (0 missing,
  0 type mismatches); 109 additional unnamed tables discovered.
- Data spot-checked against raw ROM bytes (20 tables, all match).
- Cal region auto-detected via 'Copr.DENSO' header (handles 0x6c000 / 0x6d000 /
  0x71000 layouts).
- Scalars (extract_scalars.py): 14 seeded float32 constants located by exact bit
  pattern in all 11 ROMs. Every seed's reference-ROM (60E15120_N3J1E) address was
  re-read from the untouched ROM and is asserted by the script + tests (e.g.
  fuel_load_scale 0.07196 = 0x3d935fc4 @0x78170, stoich_afr 14.7 = 0x416b3333
  @0x3e7ec, load_cell_scale 0.6345 = 0x3f226e98 @0x7a088). One cross-ROM difference found:
  injector_flow_secondary_cc_min (475.93 = 0x43edf70a) is absent in
  60E0E700_N3YLEE, which uses 608.0/626.224 (0x44180000/0x441c8e5b) at
  0x76ccc-0x76cd0 next to its primary-flow literal - different secondary
  injectors on that market ROM. Tests: tests/test_extract_scalars.py.
