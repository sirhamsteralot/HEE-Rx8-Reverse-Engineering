# Default-deny egress allowlist for the agent box (tinyproxy, ERE per line).
# Add a destination only when the agent genuinely needs it, and keep it as
# narrow as possible: FilterDefaultDeny in tinyproxy.conf blocks the rest.
#
# The agent CLI's model API, and everything its sign-in flow talks to
# (auth./chat./console./admin.mistral.ai, incl. the regional api.us./api.eu.
# hosts): the console sign-in start, poll and key-exchange requests all land on
# this pattern, so no extra line is needed for signing in from inside the box.
^(.+\.)?mistral\.ai$

# Feature-flag evaluation for the CLI (first-party Mistral, fetched at startup).
# Refusing it costs a "GrowthBook eval request failed" warning per session and
# never blocks a session or a sign-in; delete this line if you would rather the
# box not report flag evaluations.
^experiments\.mistral\.services$

# GitHub over HTTPS: git clone/fetch and push, the REST/GraphQL API (gh, the
# GitHub connector), archive downloads, raw files, release assets and git-lfs
# object downloads. Only 443 is permitted and the box carries no GitHub
# credentials of its own, so this is read egress for public repositories unless
# you inject a token; delete the block to keep the box off GitHub entirely.
^github\.com$
^api\.github\.com$
^codeload\.github\.com$
^raw\.githubusercontent\.com$
^objects\.githubusercontent\.com$
^media\.githubusercontent\.com$
^github-cloud\.s3\.amazonaws\.com$
